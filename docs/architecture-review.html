Top Recommendation

1. Collapse Flow Graph construction into a deep module

Control Flow Graph construction is the foundational engine of the entire platform: downstream dominator analysis, loop detection, fingerprinting, and UI rendering all depend directly on its invariants. Consolidating leader detection, block partitioning, edge routing, reachability, and complexity behind one deep interface eliminates four shallow modules, closes an inline import leak, and yields the highest leverage for callers and tests.
